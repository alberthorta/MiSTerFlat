PlayStation memory cards

One card per game folder (saves/PSX). Download gives a .mcd file that PC tools and emulators read. Upload takes .mcd, .mcr, .sav, .gme or .vmp; the old card is backed up first. In the game, save to the card in slot 1. MiSTer writes the card to the SD when you use "Save Memory Card" in the OSD, or on its own with Autosave.

The PSX core is running. It reads the card only when a disc loads (a reset is not enough), and with "Save to SDCard: On Open OSD" it writes its own copy when you open the OSD. After uploading, let the page reload the game, and do not open the OSD before that.

HDMI

Try these if the screen goes off and on when a core loads. Both keep 1920x1080 at 60 Hz. If the screen stays black after a change, set it back here from the phone, then reload a core.

Edit custom preset

Presets/Custom. The " - Vertical" copy is updated too, with the filters swapped and the mask rotated. Scanlines "SLA_Dk_XXX_Br_YYY": Dk = how dark the lines are, Br = how much bright parts fill them.

Controllers

DualShock 4 and DualSense pads also report their tilt like a stick, so the character can move by itself. With this on, MiSTerManager keeps those sensors from MiSTer. Buttons, sticks and touchpad are not affected.

MiSTerLily display

Only the program is written: the display keeps its settings and start-up picture. It takes about 15 s. Do not unplug the display while it runs.
