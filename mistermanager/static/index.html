PlayStation memory cards

How cards work

One card per game folder in saves/PSX. Download gives a .mcd file that PC tools and emulators read. Upload takes .mcd, .mcr, .sav, .gme or .vmp; the old card is backed up first.

In the game, save to the card in slot 1. MiSTer writes the card to the SD when you use “Save Memory Card” in the OSD, or on its own with Autosave. With “Save to SDCard: On Open OSD” the core writes its own copy when you open the OSD.
